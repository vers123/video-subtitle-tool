字幕提取优先级回退流程

对每个视频文件，按以下优先级依次尝试提取字幕，成功即停止，进入下一个视频：

1

环境检测

检查 Python、ffmpeg 是否可用；检测 GPU 型号和显存，自动选择 Whisper 模型（够用则 medium，不足则 small）

2

尝试提取软字幕（ffprobe + ffmpeg）

检测视频是否包含字幕轨道。有则直接提取为 SRT，文件名标记 xxx_embedded.srt

3

回退：OCR 识别硬字幕（PaddleOCR）

无软字幕时，截取视频画面底部区域，用 PaddleOCR 识别烧录字幕。生成 xxx_ocr.srt

4

最终回退：Whisper 语音转文字

OCR 无法识别时，提取音轨用 Whisper 转录。生成 xxx_whisper.srt

5

保存与清理

字幕保存到 subtitles/视频文件名/ 子文件夹，自动清理临时 WAV 文件

Whisper 模型规格：medium 参数量 769M，显存需求 ~5.5GB，英文 WER ~3.0%，适合视频字幕生成 [$TRAE_REF](https://openwhispr.com/blog/whisper-model-sizes-explained)。GPU 不足时自动降级为 small（244M，~2GB 显存）。

    在执行任何操作前，先编写完整的计划文档，包含技术方案、目录结构、执行步骤

    列出待确认项和待补充项，逐一向用户提问确认

    将确认结果整合，形成最终可执行版本（即本文档）

  2. 创建 Python 虚拟环境

    在项目根目录创建虚拟环境：python -m venv venv

    激活虚拟环境后安装依赖：pip install -r requirements.txt

    所有 Python 包均在虚拟环境中安装，不污染系统环境

    README 中提供虚拟环境创建、激活、依赖安装的完整步骤

  3. 环境检测模块

    编写 env_check.py：检测 Python 版本、ffmpeg 是否可用、NVIDIA GPU 型号及显存

    根据 GPU 情况自动选择 Whisper 模型：显存 >= 6GB 用 medium，否则用 small

    缺失依赖时输出安装指引

  4. 配置文件

    编写 config.py，定义可配置参数：视频输入路径、字幕输出路径、Whisper 模型、目标语言、输出格式、支持扩展名、OCR 截取区域

  5. 软字幕提取模块

    编写 subtitle_extractor.py：用 ffprobe 检测字幕轨道，有则用 ffmpeg 提取为 SRT，无则返回 None

  6. 硬字幕 OCR 模块

    编写 ocr_subtitle.py：截取视频底部区域，PaddleOCR 识别文字，按帧时间戳生成字幕，相邻相同文本合并去重

  7. 语音转文字模块

    编写 transcriber.py：ffmpeg 提取音轨为 16kHz mono WAV，Whisper 模型转录，自动检测语言

  8. 字幕写入模块

    编写 subtitle_writer.py：统一各来源字幕为标准 SRT，按提取方式添加文件名后缀

  9. 文件管理模块

    编写 file_utils.py：扫描 video/ 下支持格式文件，创建输出子文件夹，保存 SRT 后清理临时文件，不支持格式报错跳过

  10. 主程序调度

    编写 main.py：环境检测 → 遍历视频 → 三级回退提取 → 保存字幕 → 进度显示 + 异常处理 + 错误日志

    支持命令行参数：--input 指定单个视频、--method 指定提取方式、--output 指定输出路径

  11. AI 编程辅助模块

    编写 ai_context/AI_GUIDE.md：项目概述、架构图、目录结构、模块说明、配置参数、依赖清单、运行方式

    编写 ai_context/module_specs/ 各模块接口规格文档

    编写 ai_context/coding_conventions.md：命名约定、代码风格、注释格式、错误处理模式

    编写 ai_context/check_ai_docs.py：文档同步检查脚本

    编写根目录 .cursorrules 和 CLAUDE.md 适配文件

  12. 依赖与文档

    编写 requirements.txt 和 README.md

  13. 功能测试

    准备测试视频，验证三级回退策略和字幕输出正确性

python main.py --input video/demo_video_01.mp4 # 或指定提取方式 python main.py --input video/demo_video_01.mp4 --method whisper # 或指定输出路径 python main.py --input video/demo_video_01.mp4 --output custom_subtitles/
